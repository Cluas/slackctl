slackctl

A fast, single-binary Slack CLI for AI agents and humans. Read threads, send messages, search, upload files and stream real-time events as JSON, using the Slack login you already have.

View on GitHub Download pkg.go.dev

Why slackctl

  • Single binary. No Node.js, no runtime dependencies. macOS, Linux and Windows, amd64 and arm64.
  • No bot token needed. Imports your session from Slack Desktop, Chrome, Brave or Firefox (xoxc token plus d cookie), so it works in workspaces where you cannot install an app.
  • Made for agents. Every command prints JSON. Ships an agent skill for Claude Code, Codex and Gemini CLI.
  • Covers the daily work. Messages, threads, unread, saved-for-later, search, users, channels, canvases, reactions and file uploads.
  • Real-time. slackctl listen streams new messages, mentions and DMs as JSON Lines.

Install

Homebrew (macOS / Linux)

brew tap cluas/tap
brew install slackctl

Scoop (Windows)

scoop bucket add cluas https://github.com/cluas/scoop-bucket
scoop install slackctl

Go

go install github.com/cluas/slackctl/cmd/slackctl@latest

Prebuilt archives for every platform are on the releases page.

Quick start

# Import credentials from Slack Desktop (or import-chrome / import-firefox / import-brave)
slackctl auth import-desktop
slackctl auth test

# Read a thread from its URL
slackctl message get https://myteam.slack.com/archives/C0123/p1700000000000100

# Post a message
slackctl message send '#general' 'deploy finished'

# Search
slackctl search messages 'from:@alice incident'

# Wait for mentions and DMs in real time
slackctl listen --mentions-or-dms

Commands

GroupWhat it does
authImport or add credentials, test them, switch the default workspace
messageGet, list, send, edit and delete messages; reactions; unread; saved-for-later list
fileUpload (including from stdin), download, list and delete files
searchSearch messages and files
channelList conversations, create channels, invite users, mark as read
userList users and look one up, including their custom status
canvasFetch a canvas as Markdown
listenStream real-time events as JSON Lines

Use it from an AI agent

The repository ships an agent skill that teaches Claude Code, Codex, Gemini CLI and similar agents how to call slackctl.

npx skills add cluas/slackctl -g

Then ask your agent things like "summarize this Slack thread", "what did I miss in #release" or "tell me when Alice replies".

Credentials

Credentials are stored in ~/.config/agent-slack/credentials.json, compatible with agent-slack. Environment variables SLACK_TOKEN, SLACK_COOKIE_D and SLACK_WORKSPACE_URL take precedence.
